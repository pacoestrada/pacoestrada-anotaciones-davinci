# Anotaciones para DaVinci · Paco Estrada · v1.1.0

Colección de anotaciones de Fusion para DaVinci Resolve en Windows, macOS y Linux. Probada en Resolve Studio 21. El instalador contiene las mismas plantillas que la versión de prueba 0.2.

Incluye 27 títulos para superponer y tres efectos de desenfoque para aplicar al clip. Descarga el archivo `.drfx` y ábrelo con Resolve. Si ya tienes instalada la 0.2, puedes seguir usándola o retirarla antes de instalar la 1.1.0 para evitar duplicados.

El README incluye el catálogo, las instrucciones de instalación y desinstalación y una guía de uso. Licencia MIT.
